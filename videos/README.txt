Put your video clips in this folder (for example hotel-1.mp4, hotel-2.mp4, reviews-1.mp4,
hardrock-1.mp4, influencer-1.mp4, influencer-2.mp4, influencer-3.mp4).

Then open index.html, find the line that starts with  var VIDEOS = {  and fill in each file name,
for example:  "hotel-1": "hotel-1.mp4"

Tips: use .mp4 (H.264), keep each clip under about 25 MB so you can upload it in the browser,
and trim long clips to a short teaser.
